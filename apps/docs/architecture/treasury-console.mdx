<Warning>
**There is no treasury console in the Stellar build.** The console that shipped with Corridor's earlier Tempo prototype read Tempo, Solana and the prototype's shielded lane. Its server was removed when Stellar became the only hub, rather than left reporting a chain this repository no longer settles on.
</Warning>

## What exists today

The reporting the console fronted runs from the command line, against the Stellar accounts a company already operates:

```bash
CORRIDOR_WATCH=GABC…,GDEF… pnpm watch:report
```

It polls Horizon for each account's payments, matches them against the ledger, and prints a summary and every movement that is not `matched`. Nothing moves and no key is needed. See [Read-only pilot](/flows/read-only-pilot).

`pnpm stellar:payout` prints the saga's steps, the anchor order, the ledger invariants and the customer's closing balance — the same facts a settlement timeline would show, for one run.

## What a console would show

When one is built, these are the panels the engines already produce the data for:

| Panel | Data it would read |
|---|---|
| Corridor board | `Accounts.customer` and `.customerHold` balances per customer and corridor |
| Settlement timeline | `saga_steps` and `saga_events`, with a stellar.expert link per on-chain step |
| Venue balances | Vault and clearing balances per venue, with clearing pairs netting to zero |
| Reconciliation | `summarize(reconcile(...))`, the vault check and booked fees |
| Exceptions queue | `reconcileReadOnly` statuses: short, over, missing, unexpected |
| Pre-funding forecast | Daily outflow per customer against the hub balance |

None of that is built. It is listed here so a reviewer can see the gap is a user interface rather than a missing engine, and the [Roadmap](/status/roadmap) says where it sits.

## The prototype's console

The earlier console is kept as a static replay, as evidence of the prototype: a recording of real Tempo and Solana runs from 11 October 2026. Every figure in it is a Tempo-era run, not a Stellar one, and it is labelled as such. It is not part of this build and nothing in it reflects the Stellar code.
