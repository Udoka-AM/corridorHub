Corridor is a TypeScript monorepo (pnpm workspaces) with one Rust service for FROST signing. The ledger runs on embedded Postgres (PGlite) locally, so there is no database to install, and test keys are generated and funded from the Tempo testnet faucet on first run.

## Prerequisites

- Node.js 22 or later and pnpm 9
- Rust stable, only for the FROST signer and the Zcash tooling
- For the shielded lane: [`zcash-devtool`](https://github.com/zcash/zcash-devtool) built locally

## Run it

<Steps>
  <Step title="Clone and install">
    ```bash
    cd corridor
    pnpm install
    ```
  </Step>
  <Step title="Verify">
    ```bash
    pnpm typecheck
    pnpm test
    ```
    107 tests cover the ledger invariants, the reference codec, routing and hub enforcement, the saga engine (forced failures, compensation order, lease fencing), the mainnet Across and payout legs (fees, partner rounding, slow fills, crash recovery), signers, partner adapters, webhooks, the Solana memo leg, ZIP-321 batches, NEAR quotes and vault accounting.
  </Step>
  <Step title="A first memo transfer on Tempo">
    ```bash
    pnpm tempo:smoke
    ```
    Generates testnet keys into `.env.local` on first run, funds them from the Moderato faucet, sends a `transferWithMemo`, finds it again by its indexed memo topic and books it exactly once.
  </Step>
  <Step title="Run the flows">
    ```bash
    pnpm payout:demo     # EUR → NGN payout, including a forced partner failure that compensates on-chain
    pnpm importer:demo   # NGN collected into the hub, then CNY paid to a supplier
    pnpm zcash:frost     # FROST 2-of-3 shielded batch on Zcash testnet
    ```
  </Step>
  <Step title="Open the treasury console">
    ```bash
    pnpm console        # http://localhost:4400
    ```
    Run a payout, a payout with a forced partner failure, and an importer flow from the console, then watch every movement reconcile. The console owns the local ledger, so stop other flows before starting it: the embedded Postgres has a single owner.
  </Step>
</Steps>

## Scripts

| Command | What it does |
|---|---|
| `pnpm tempo:smoke` | Memo transfer on Moderato, observed and booked once |
| `pnpm payout:demo` | Public payout saga with compensation |
| `pnpm importer:demo` | Collection then supplier payout across the hub |
| `pnpm zcash:batch` | Single-key shielded batch with encrypted memos |
| `pnpm zcash:frost` | Threshold-controlled shielded batch |
| `pnpm across:testnet` | Live Across deposit on testnet (Base Sepolia → Solana devnet) |
| `pnpm watch:report <config>` | Read-only reconciliation of existing wallets against payout records |
| `pnpm mainnet:wallets` | Create or inspect the mainnet vaults (keys stay local) |
| `pnpm mainnet:saga` | Mainnet payouts through the saga engine, with an on-chain vs ledger check of every vault |
| `pnpm console` | Treasury console and JSON API |
| `pnpm console:snapshot` | Record the running console as the static public replay |

<Warning>
Private keys are written to `.env.local` and `.keys/`, both gitignored. Never commit them. The console snapshot refuses to publish if any value from either location appears in its output.
</Warning>

## Repository layout

```text
packages/
  core/            Venues, currencies, money, the Corridor Reference codec
  ledger/          Double-entry ledger with invariants (PGlite / Postgres)
  routing/         Route graph and planner, hub enforcement
  saga/            Durable saga engine with leases, fencing and compensation
  signer/          Signer interface: local, AWS KMS and Turnkey adapters
  legs/            Leg implementations (Across bridge, partner payout and collection, credit, shielded)
  chain-tempo/     Tempo client, memo transfers, observer
  chain-solana/    Stablecoin registry, memo transfers, watcher
  chain-evm/       Base stablecoins and watcher
  chain-zcash/     zcash-devtool wallet, ZIP-321, FROST orchestration
  bridge-across/   Across Swap API: quote, execute, fill tracking
  swap-near/       NEAR Intents 1Click quotes and status
  partners/        RampPartner interface, Paj adapter, mock partner
  webhooks/        Signed partner webhook ingest
  recon/           Reconciliation and vault accounting
services/
  zcash-frost/     corridor-frost: FROST(RedPallas) keygen and signing (Rust)
apps/
  console/         Treasury console
  site/            Public website and console replay
  docs/            This documentation
```
