Base plays three roles in Corridor.

## 1. The bridge midpoint

Across has no direct Tempo ↔ Solana route, so every hub ↔ Solana movement is two hops through Base USDC (`0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`). Between hops, the funds sit in a Corridor-owned **relay wallet** on Base, so they are never in an unowned address and the ledger always knows where they are.

## 2. Ready for Base-settling partners

Today's naira partner, Paj, settles on **Solana only**, so naira payouts take both hops (Tempo → Base → Solana → Paj). The route graph already supports partners that pay out straight from Base USDC: listing a currency in `BASE_PAYOUT_CURRENCIES` adds a `partner.payout` edge from `base/USDC`, and the planner's cheapest-path search then picks the **one-hop** route automatically:

```text
ledger.reserve → across.bridge (Tempo → Base) → partner.payout (Base → local currency)
```

The list is empty until such a partner is live.

## 3. The mainnet shielded on-ramp

NEAR Intents has no Tempo market, so on mainnet a shielded batch leaves the hub on one Across hop to Base and swaps Base USDC → ZEC through NEAR Intents, delivered to the vault's unified address.

```text
ledger.reserve → across.bridge (Tempo → Base) → near.swap (Base USDC → ZEC) → zcash.shieldedBatch
```
