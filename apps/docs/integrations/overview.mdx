Corridor does not pick one chain for everything. It composes chains by role, and every role is reconciled by the same Corridor Reference.

| Leg | Testnet (demo) | Mainnet |
|---|---|---|
| Tempo | Moderato, chain 42431 | Chain 4217 |
| Across | Base Sepolia ⇄ Solana devnet (no Tempo testnet deployment) | Tempo ⇄ Base ⇄ Solana |
| Base | Base Sepolia (84532) | Base (8453) |
| Solana | Devnet | Mainnet |
| Zcash | Testnet, Ironwood pool | Mainnet, Ironwood pool |
| NEAR Intents | Live mainnet quotes; delivery is testnet ZEC | 1Click swaps from Base USDC |
