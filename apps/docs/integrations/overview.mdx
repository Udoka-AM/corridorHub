Corridor settles in one place. **Stellar is the hub**, anchors are the fiat spokes and they settle on the hub itself, so the common payout path has no bridge in it at all. Everything is reconciled by the same 32-byte Corridor Reference.

## What settles where

| Role | Venue | Status |
|---|---|---|
| Customer balances, treasury, clearing | Stellar, in USDC | Running on testnet |
| Local currency in and out | Anchors, over SEP-31 | Adapter built; **no anchor signed** |
| Naira payouts | A licensed partner on Solana | Carried over from the prototype; the hop to reach it is not built |
| USDC inflows | Base and Solana, over CCTP | Edges declared; **the leg is not built** |

## Networks and environments

| | Testnet | Mainnet |
|---|---|---|
| Stellar | Test network, funded by Friendbot. Payments with references, read back off Horizon | Public network. Code paths identical; **no run yet** |
| Anchors | `MockPartner` with the same lifecycle and signed webhooks; `SepAnchor` against a stubbed anchor | None signed |
| CCTP | `bridge.simulated`, whose Stellar side is real | Leg not built |
| Solana | Devnet | Carried over from the prototype for the naira corridor |
| Base | Base Sepolia | Carried over from the prototype |
