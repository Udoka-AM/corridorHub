## Context

Across supports Tempo mainnet but has no Tempo testnet deployment. A deployment on Moderato cannot bridge Tempo value through Across.

## Decision

**Build against the live Across Swap API**, verified with live mainnet quotes, and use `bridge.simulated`, which has the same interface, only on testnet. The simulated leg moves real pathUSD on Tempo to an escrow with the reference as memo and simulates only the far side, and its bookings are marked `simulated`.

## Consequences

- Mainnet needs no change to the planner: it selects `across.bridge` edges in the mainnet environment.
- The live route paid out on mainnet on 11 Oct 2026: Tempo → Base → Solana → Paj → a Nigerian bank account in 74 seconds ([Evidence](/status/evidence#live-on-mainnet)).
- Testnet runs show real Tempo movements and real compensation refunds.
- A live Across testnet deposit (Base Sepolia → Solana devnet) completed CCTP attestation but stalled on Across's testnet relayer; this is recorded, not hidden.

## Alternatives rejected

- **Simulate everything:** no evidence the integration works.
- **Wait for mainnet funds before building other lanes:** blocks every lane on one dependency.
