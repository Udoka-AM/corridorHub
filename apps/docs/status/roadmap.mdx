## Production hardening

| Area | Today | Production |
|---|---|---|
| Ledger | PGlite (embedded Postgres) | Managed Postgres, same schema and triggers |
| Custody | Signer interface on every vault; AWS KMS and Turnkey adapters | The customer's KMS or MPC for every vault; a Fireblocks adapter (raw signing enabled) |
| Routing | The planner enforces the Tempo hub | Tempo-first, not Tempo-only: direct Solana routes when the sender already holds Solana stablecoins, with measured cost per hop |
| Stablecoins | Payouts fund from pathUSD or USDC.e; USDC, USDT, PYUSD and EURC watched and reconciled | Swap legs so USDT, PYUSD and EURC fund payouts directly; USDT on Tron for African payout liquidity |
| Liquidity | Customer float in its own vault | Liquidity providers plugged in as venues |
| Compliance | Viewing keys for the shielded lane | Address screening (Chainalysis or TRM), a Travel Rule provider hook, audit exports |
| FROST | Trusted-dealer keygen; both rounds in one process | Distributed key generation; each signer on its own device relaying through `frostd` |
| Console | Local, without authentication | Authenticated and role-based, with approval and disclosure endpoints behind access control |
| Gas | Booked from the chain on every venue | Gas paid in stablecoins on every chain (a USDC paymaster on Base, a fee relayer on Solana) and batched bridging per partner |
| Zcash stack | `zcash-devtool` | Z3 node stack and Zallet |

## Known limitations

<AccordionGroup>
  <Accordion title="Solana account rent on every Paj payout">
    Paj issues a one-off deposit address per order, so each payout creates a new token account and costs about 0.002 SOL in rent, more than the network fee. It is booked as `expense:account-rent`. The fix is a reusable deposit address with a memo, or delivery straight from the bridge to the partner.
  </Accordion>
  <Accordion title="No Across deployment on Tempo testnet">
    Across has no Tempo testnet, and its testnet CCTP relayer did not complete a Base Sepolia → Solana devnet mint. Testnet routes use `bridge.simulated`, which has the same interface and bookings; mainnet uses the live bridge.
  </Accordion>
  <Accordion title="Non-USD gas on Tempo">
    Tempo accepts USD stablecoins as fee tokens today. Vaults pay gas in pathUSD from the owner's float, so customer balances never fund gas.
  </Accordion>
</AccordionGroup>
